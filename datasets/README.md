# Sentrix Datasets

This directory holds network traffic datasets used for training and evaluating Sentrix models:

- `CICIDS2017/`: Canadian Institute for Cybersecurity IDS 2017 flow feature CSVs.
- `NSL-KDD/`: NSL-KDD benchmark dataset files.
- `mitre/`: MITRE ATT&CK technique mapping definitions (`attack_technique_map.json`).
- `demo/`: Curated test and demonstration traffic replay traces.

*Note: Raw CSVs and large pcap files are gitignored.*
